# VoiceOS Integrations Marketplace

A community-built marketplace, directory, and easy-install hub for VoiceOS MCP integrations.

🌐 **Live site:** https://gabeperez.github.io/voiceos-integrations

---

## Featured Integrations

| Integration | Description | Platform |
|---|---|---|
| [🚀 macOS App Launcher](https://github.com/gabeperez/macos-app-launcher) | Open, focus, quit apps and set volume by voice | macOS |
| [🌴 Poke Bridge](https://github.com/gabeperez/poke-bridge) | Voice-activate your iMessage AI agent | macOS / Windows |

---

## Submit an Integration

Open a PR adding your integration card to `index.html`, or [open an issue](https://github.com/gabeperez/voiceos-integrations/issues) with your repo link and we'll add it.

**Required info:**
- Repo URL
- Short description
- Supported platforms
- MCP tools exposed

---

## Run Locally

Just open `index.html` in your browser — no build step needed.
